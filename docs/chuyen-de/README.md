# Hub chủ đề

**Mô tả:** Mười hub gom link theo việc cần làm (POS, kho, API…).

- [Kiến trúc hệ thống](kien-truc-he-thong/) — Sơ đồ tổng thể: pos-app, api-server, Postgres, offline, cloud-sync — đọc đầu tiên.
- [Đăng nhập và phiên làm việc](dang-nhap-va-phien/) — JWT, shop đang chọn, hub shop, quyền menu.
- [POS và đơn hàng](pos-va-don-hang/) — Quầy bán, giỏ hàng, thanh toán, ca làm việc, hủy đơn.
- [Sản phẩm và tồn kho](san-pham-va-kho/) — Danh mục SP, tồn shop, phiếu nhập/xuất, PO.
- [Hóa đơn đầu vào (VAT mua vào)](hoa-don-dau-vao/) — Import PDF/Excel, kéo CQT, MST lọc, ghép hàng, nhập kho.
- [Hóa đơn bán ra (Viettel)](hoa-don-ban-ra/) — Phát hành HĐ VAT từ POS, tra cứu, form công khai.
- [Chuỗi và nhiều cửa hàng](chuoi-cua-hang/) — Tổ chức, shop, kho, điều chuyển, dashboard chuỗi.
- [An ninh và chặn truy cập](an-ninh-truy-cap/) — Chặn IP/thiết bị, quan sát truy cập, super_admin.
- [Offline và đồng bộ](offline-dong-bo/) — IndexedDB, checkout offline, API sync.
- [Trợ lý AI, widget, đếm khách](tro-ly-widget/) — Agent chat, widget Android, ESP32 visitor-counts.
